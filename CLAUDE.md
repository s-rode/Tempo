# Tempo

Tempo is a macOS desktop app built with Electron and React (`electron-app`), with a `server` and `shared` package alongside.

## UI work

For any UI or interaction work, follow the `macos-design-guidelines` skill (`.claude/skills/macos-design-guidelines/SKILL.md`) in spirit: Tempo should feel like it belongs on the Mac. Treat the skill as the idea of macOS design, not a checklist where everything has to match exactly. Its Swift and AppKit snippets are illustrative, so translate the intent into Electron and React, and skip rules that do not fit Tempo.
